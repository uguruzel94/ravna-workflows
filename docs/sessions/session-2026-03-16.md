### Changes

1. **Outscraper integration** — Replaces Brave Search discovery with Google Maps API
   - Structured data: phone, address, ratings, review count, official category
   - Cost: ~$0.003/record, 50-record hard limit (~$0.15/run)

2. **Two-stage filtering** — Pre-filter by Maps metadata before scraping
   - Stage 1: Discard obvious non-fits (no website, >200 reviews, rating <3.5, intent mismatch)
   - Stage 2: Website scraping + email extraction only for survivors
   - Eliminates 40-60% of records without any scraping cost

3. **Contact data extraction** — Phone + address + email
   - Phone, address: from Outscraper (Google Maps)
   - Email: regex extraction from website scraping
   - DB columns added via Supabase migration (phone TEXT, address TEXT, email TEXT)

4. **Evidence-based ICP scoring** — Replaces assumption-based rubric
   - Each of 5 points requires specific evidence (not just category guessing)
   - Examples: team size signal (job listings, LinkedIn mentions, /about page counts)
   - No more 10/10 scores for companies with no real data

5. **Intent-driven matching** — Natural language replaces hardcoded logic
   - Input: `intent: "Tıbbi cihaz distribütörleri, hastanelere satış. Dişçi değil."`
   - Sonnet evaluates each company against intent + Maps category
   - Clients describe ICP in plain language, no SKILL.md edits needed

6. **Fixed Telegram formatting** — jq + MarkdownV2
   - Eliminated newline collapse bug from v2
   - Proper escaping of special chars (`.` `-` `(` `)` `|` `{` `}`)
   - Turkish formatting with bullets, emojis, line breaks

7. **No parallelism cap** — default 10, user-controlled
   - v2 had hardcoded max=5 companies (artificial limit)
   - v3: count parameter respects user input, defaults to 10

## FOLLOW-UP: Async API Fix (same session)

**Problem:** Outscraper Maps Search API uses async task pattern by default. Returns `{status: "Pending"}` requiring polling loop — SKILL.md had no polling logic, so all discovery attempts were stuck.

**Root cause:** API documentation default behavior differs from what was assumed during SKILL.md design.

**Fix:** One-line change to STEP 1 curl command:
```bash
# Before:
curl -s "https://api.app.outscraper.com/maps/search" ...

# After:
curl -s --max-time 90 "https://api.app.outscraper.com/maps/search" ... \
  --data-urlencode "async=false" \
  ...
```

- `async=false` → makes API call synchronous (blocking), returns results directly
- `--max-time 90` → allows up to 90 seconds for API to complete

**Impact:** Unblocks entire discovery pipeline. SKILL.md v3 ready for testing.
